# Organic / Natural Graphic Direction

The specimen should read as a graphic design system rather than a photography-first editorial page.

- Botanical illustration is structural, not decoration.
- Organic blobs, circles, curves and irregular silhouettes create composition.
- Typography, shapes, patterns and botanical marks overlap intentionally.
- Use forest, olive, sage, cream, ochre and terracotta as the core palette.
- Introduce dots, rings, stripes and hand-drawn linework as restrained texture.
- Preserve the existing interactive anatomy studies and Colour Lab.
- Keep the Ryūma architecture and responsive behaviour intact.
